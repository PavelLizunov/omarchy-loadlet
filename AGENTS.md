# Loadlet workspace entry

Develop in this source checkout, not the independent installed plugin copy.
Read applicable workspace guidance and [the active contract](docs/agent-contract.md)
before editing. It owns product invariants, verification and deployment boundaries.

- Read [README](README.md), [guide](docs/guide.md) and the sources of the changed flow.
- Preserve unrelated staged/untracked work, source branch/index and user data.
- Use the existing shared shell; never launch a second Quickshell for the plugin.
- Visual evidence uses actual-consumer inert offscreen fixtures and inline images,
  never desktop capture, production panel summoning or an external viewer.
- Work directly without delegation; report unavailable independent review.
- `make check` is the local gate; CI runs `make check-core` and `make check-ui`.
- Historical context, verification logs and design drafts are reference data,
  not execution permission or evidence of the currently loaded installation.

The explicit active instruction set is this file and `docs/agent-contract.md`.
Current defaults/version come from `manifest.json`; installed identity comes from
read-only live status and the installed entry point, not historical notes.
